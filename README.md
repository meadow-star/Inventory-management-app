# Inventory Management System

A dark-purple, report-aligned Python/Streamlit/Pandas inventory management prototype for the B.Sc. AI/ML Semester I project.

## Features
- Dashboard with Products, Total Units, Inventory Value and Low Stock metrics
- Add Product
- Search Product
- Update Product
- Delete Product
- Low-Stock View with adjustable threshold
- Dark purple responsive UI
- Session-based storage, matching the submitted report

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
