# Inventory Management System

Python + Streamlit + Pandas implementation aligned with the submitted project report.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Features

- Dashboard metrics: Products, Total Units, Inventory Value, Low Stock
- Add Product
- Search Product
- Update Product
- Delete Product
- Low-Stock View
- Session-based storage, matching the report's stated prototype limitations

## Deploy free on Streamlit Community Cloud

1. Upload `app.py`, `requirements.txt`, and this README to a GitHub repository.
2. Sign in to Streamlit Community Cloud using GitHub.
3. Create an app from the repository.
4. Set the main file to `app.py`.
5. Deploy.

No database or environment variables are required for this report-aligned prototype.
